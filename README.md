# KS-15 한의학적 체질 진단 시스템

**의료급 정밀 체질 진단** - 실제 의료 데이터 기반 KS-15 표준 시스템

## 🎯 프로젝트 개요

KS-15 표준을 기반으로 한 **의료급 체질 진단 시스템**입니다. 실제 의료 연구 데이터(DBF 파일)를 기반으로 하여 정확하고 신뢰성 있는 진단을 제공합니다.

### 🏥 의료급 시스템 특징

- **3체질 시스템**: 태음인, 소양인, 소음인 (의료 표준에 따라 태양인 제외)
- **실제 의료 데이터**: Visual FoxPro DBF 파일에서 추출한 검증된 데이터
- **성별별 가중치**: 남성/여성 다른 반응 패턴 정확히 반영
- **BMI 통합 진단**: 체형 정보를 진단 알고리즘에 포함
- **연령대 조정**: 나이에 따른 체질 특성 변화 고려
- **신뢰도 계산**: 과학적 근거 기반 진단 확신도 제공

## ✨ 주요 기능

### 🔬 **의료 데이터 기반 진단**
- **12개 표준 질문**: KS-15 의료 표준에 따른 검증된 질문지
- **다차원 평가**: 성격, 행동, 소화, 체온, 배변 등 종합 분석
- **과학적 가중치**: 의료 연구 데이터에서 도출된 정확한 계산식

### 🧬 **개인 맞춤형 분석**
- **사용자 정보 수집**: 성별, 나이, 키, 몸무게 입력
- **BMI 자동 계산**: 체형에 따른 체질 성향 보정
- **종합 분석 리포트**: 개인별 맞춤 건강 관리 조언

### 🎨 **사용자 경험**
- **직관적 인터페이스**: 단계별 안내와 명확한 진행률 표시
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 완벽 지원
- **다크모드**: 시스템 테마 자동 감지 및 수동 전환
- **결과 공유**: 소셜 미디어, 클립보드, 파일 다운로드

## 🏗️ 기술 스택

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **PWA**: next-pwa (오프라인 지원)
- **Data**: 의료 DBF 파일 기반
- **Deployment**: Vercel

## 📊 KS-15 진단 알고리즘

### 진단 과정

1. **기본 점수 계산**: 12개 질문 답변에 따른 성별별 가중치 적용
2. **BMI 조정**: 체형에 따른 체질 성향 보정값 추가
3. **연령 조정**: 나이대별 체질 특성 변화 반영
4. **최종 진단**: 가장 높은 점수의 체질로 결정
5. **신뢰도 계산**: 점수 차이 기반 진단 확신도 산출

### 의료 데이터 검증

- ✅ 실제 의료 연구 DBF 파일 기반
- ✅ 성별별 반응 패턴 검증
- ✅ 3체질 시스템 의료 표준 준수
- ✅ 진단 정확도 통계적 검증
